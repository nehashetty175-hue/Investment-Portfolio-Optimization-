# 📈 Investment Portfolio Optimization Analysis (Excel)

## 📌 Project Overview

This project analyzes investment portfolios using Microsoft Excel, Power Query, and Power Pivot. The objective is to evaluate portfolio performance, profitability, risk exposure, and investment diversification through an interactive executive dashboard.

The project includes data cleaning, data modeling, KPI creation, Pivot Tables, Pivot Charts, and business insights to support investment decision-making.


##  Project Objectives

- Analyze portfolio performance across different sectors and asset types.
- Measure portfolio value, profit, and investment returns.
- Evaluate investment risk using Beta and Volatility.
- Monitor dividend yield and portfolio diversification.
- Build an interactive dashboard for business users.
